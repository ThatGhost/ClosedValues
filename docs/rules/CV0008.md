# CV0008: Closed value declares a generated member

## Cause

The closed value type declares a member with the name of a member that the generator writes:

| Name | Generated when |
|---|---|
| `All`, `allInstances`, `FromName`, `TryFromName`, `ClosedValueTypeConverter`, `ClosedValueJsonConverter` | Always. |
| `Equals`, `GetHashCode`, `operator ==`, `operator !=` | Always, except in a record or record struct, where the compiler writes them and an own `Equals` is allowed. |
| `Match` | The type has at least one instance. |
| `TryParse`, `Parse`, `implicit operator`, `explicit operator` | The type has exactly one member of a basic type. |
| `CompareTo`, `operator <`, `operator <=`, `operator >`, `operator >=` | The type has exactly one member of a basic type other than `bool` or `string`. |

## Rule

Two members with the same name give a compiler error that points at the generated code. This rule names the
member in your code instead.

`ToString()` is not on the list. When you declare it, the generator skips its own.

## Fix

Rename the member.

```csharp
public static IEnumerable<Color> All => ...;      // CV0008
public static IEnumerable<Color> Warm => ...;     // correct
```
