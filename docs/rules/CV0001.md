# CV0001: Closed value created outside its type

## Cause

Code outside the closed value type creates a new instance with `new`.

## Rule

The static readonly instances inside the type are the only values. A `new` elsewhere adds a value that `All`,
`Match` and `TryParse` do not know.

The generated constructor is private, so the compiler already blocks `new` from outside. For a class or a
record, this rule fires when the type also has an accessible constructor of its own, which
[CV0002](CV0002.md) reports as well. A struct always has a public parameterless constructor, so the rule
reports `new Color()` for a struct or a record struct. That expression creates the default value, which
[CV0006](CV0006.md) describes.

## Fix

Use one of the instances.

```csharp
Color color = new Color("Red");   // CV0001
Color color = Color.Red;          // correct
```
