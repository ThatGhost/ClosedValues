# CV0002: Closed value declares a constructor

## Cause

The closed value type declares an instance constructor or a primary constructor. A positional record, such as
`record Color(string Name)`, has a primary constructor.

## Rule

The generator writes one private constructor, with one parameter per get-only auto-property. An own
constructor can be public, which lets other code create values, or it can skip a member.

## Fix

Remove the constructor. Create the instances with the generated constructor, in the order of the properties.

```csharp
[ClosedValue]
public sealed partial class Color
{
    public Color(string name) { Name = name; }   // CV0002

    public string Name { get; }

    public static readonly Color Red = new("Red");
}
```
