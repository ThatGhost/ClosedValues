# CV0003: Closed value is not partial

## Cause

A class with `[ClosedValue]` has no `partial` modifier.

## Rule

The generator adds its members in a second part of the class. Without `partial`, the generator produces
nothing for the type.

## Fix

Add `partial`.

```csharp
[ClosedValue]
public sealed partial class Color
{
    public string Name { get; }

    public static readonly Color Red = new("Red");
}
```
