# CV0004: Closed value is not sealed

## Cause

A class with `[ClosedValue]` has no `sealed` modifier.

## Rule

A derived class can declare more values, and it can change the equality of the base type. The set is then
no longer closed.

## Fix

Add `sealed`.

```csharp
[ClosedValue]
public sealed partial class Color
{
    public string Name { get; }

    public static readonly Color Red = new("Red");
}
```
