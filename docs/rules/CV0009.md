# CV0009: Closed value key is invalid

## Cause

A property with `[ClosedValueKey]` is one of these:

- one of two or more properties with `[ClosedValueKey]`,
- not a get-only auto-property, such as a computed property,
- not of a basic type: `string`, `bool`, `char`, a number type, `DateTime` or an enum.

## Rule

The key identifies each instance. `TryParse`, `Parse`, the conversions, the ordering and the JSON and type
converters read it. A type has at most one key, and the key must be a value that these members can compare,
parse and write.

Without `[ClosedValueKey]`, a type with exactly one member of a basic type uses that member as its key.

## Fix

Mark exactly one get-only auto-property of a basic type.

```csharp
[ClosedValue]
public sealed partial class Currency
{
    [ClosedValueKey]
    public string Code { get; }

    public int Decimals { get; }

    public static readonly Currency Euro = new("EUR", 2);
}
```
