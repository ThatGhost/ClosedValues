# CV0005: Closed value has mutable state

## Cause

The closed value type declares one of these members:

- an auto-property with a `set` accessor,
- an auto-property with an `init` accessor,
- an instance field.

## Rule

Every instance is shared by the whole application. A change to one instance changes it for every user, and
it changes its equality and its hash code. A field or an `init` accessor also stays outside the generated
constructor.

## Fix

Use a get-only auto-property. A computed property, such as `public bool IsWarm => this == Red;`, is allowed.

```csharp
public string Name { get; set; }   // CV0005
public string Name { get; }        // correct
```
