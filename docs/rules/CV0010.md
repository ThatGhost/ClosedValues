# CV0010: Closed value instances share a key

## Cause

Two instances pass the same constant value for the key to the constructor.

## Rule

`TryParse`, `Parse` and the converters find an instance by its key. With two instances for one key, they always
return the first, and the second can never be read back from JSON or text.

The rule compares constant arguments only: literals, constants and `nameof`. It cannot compare a value that a
method computes at run time.

## Fix

Give every instance its own key.

```csharp
public static readonly Currency Euro = new("EUR", 2);
public static readonly Currency Dollar = new("EUR", 2);   // CV0010
public static readonly Currency Dollar = new("USD", 2);   // correct
```
