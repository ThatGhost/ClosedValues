# CV0007: Closed value has an unsupported shape

## Cause

A type with `[ClosedValue]` is one of these:

- nested inside another type,
- generic,
- static,
- a `ref struct`.

## Rule

The generator supports top-level, non-generic, non-static classes, records, structs and record structs. A
`ref struct` cannot be the type of a static field, so it cannot hold its own instances. The generator
produces nothing for these shapes.

## Fix

Move the type to the namespace level, and remove the type parameters, the `static` modifier or the `ref`
modifier.
