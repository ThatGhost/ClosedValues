# CV0007: Closed value has an unsupported shape

## Cause

A type with `[ClosedValue]` is one of these:

- nested inside another type,
- generic,
- static.

## Rule

The generator supports top-level, non-generic, non-static classes only. It produces nothing for the other
shapes.

## Fix

Move the type to the namespace level, and remove the type parameters or the `static` modifier.
