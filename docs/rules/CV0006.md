# CV0006: Closed value struct created with default

## Cause

Code outside a closed value struct or record struct uses its default value: `default`, `default(Color)`, or
`default` as the default value of a parameter.

## Rule

Every struct has a default value with each member set to its own default, such as `null` for a `string`.
That value is none of the static instances: `All` does not contain it, and `Match` throws an
`InvalidOperationException` for it.

The rule does not report `default` inside the type itself, and it does not report a class, whose default is
`null`.

The analyzer cannot see every default value. An array element, a field that is never assigned, or
`default(T)` in generic code also holds the default value.

## Fix

Use one of the instances. If the type needs a value for "none", declare it as an instance.

```csharp
Color color = default;         // CV0006
Color color = Color.Red;       // correct
Color color = Color.None;      // correct, with an instance None
```
